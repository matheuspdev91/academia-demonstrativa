# IRON HOUSE — Demo

Landing page demonstrativa independente, construída com HTML, CSS e JavaScript vanilla.

## Como visualizar

Abra `index.html` no navegador ou sirva a pasta com qualquer servidor estático.

## Assets

- `assets/iron-house-hero.png`: imagem editorial original gerada para este projeto com a ferramenta integrada de geração de imagens. Não usa marcas, pessoas reais identificáveis ou conteúdo de terceiros.
- Tipografias: Barlow Condensed, Manrope e DM Mono, servidas pelo Google Fonts.

## Motion

As revelações em scroll usam `IntersectionObserver` nativo. O site desativa animações e rolagem suave quando `prefers-reduced-motion` está habilitado. Não usa Three.js nem bibliotecas de animação.
